# Realized Volatility Timing

**Projet M2 — Trading de Volatilité**

**Auteurs :** Nathan Liesse, Alix Greggio

---

## Context
- Explore ways to time the realized volatility thanks to UKF on a State Space Model defined by Heston dynamic.
- The goal is to obtain a volaitlity to extract the estimated volatility and compute the daily implied-realised spread


## Setup

Run the following commands to install the required packages:

```bash
pip install -r requirement.txt
pip install -e .
```
